One pickup line from a robot trying to charm someone — its love language is binary, and every bit of it is saying yes. The joke grows out of being a machine, and the payoff lands in the last few words.

## Run it

```sh
python3 main.py
```

The program writes the line (72 characters, one line) to `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to write somewhere else for a local run. Pure Python standard library, no third-party packages; two runs produce byte-identical output.
